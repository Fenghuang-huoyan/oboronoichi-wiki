This page describes **oboronoichi.wiki** only. It is not TheLaba’s privacy policy, and it is not Steam’s.

## What the site stores

The site is a set of static files. It does not create an account, does not take a password, and does not ask for your Oboro no Ichi or Steam login. There is no comment box and no newsletter form in this version.

Pages you request are served as ordinary documents. This repository does not add a first-party cookie for tracking.

## Analytics

`analytics.gaId` in the site config is an empty string. The base layout prints the Google Analytics snippet only when that string is non-empty. With it empty, no gtag script is sent to the browser.

## Advertising

The Native Banner slot after the quick answer is **on** for oboronoichi.wiki. `enabled` is true. The zone id is `f9b8506a57b1d692e4617638e4743a17`. The script loads from `https://bauval.org/21/f9b8506a57b1d692e4617638e4743a17`. The container id is `container-f9b8506a57b1d692e4617638e4743a17`. Adult and sensitive categories stay off. The 404 page does not render a slot.

<Callout kind="note" title="This domain only">
That zone is the Get Code for oboronoichi.wiki. This repository does not carry a measurement id or an ad zone from any other game site. Google Analytics stays off because `analytics.gaId` is empty.
</Callout>

Steam, Discord, YouTube, and the other official links in the footer are ordinary outbound links. Their own sites set their own cookies once you leave this one. The support address thelabaofficial@gmail.com is TheLaba’s, printed on the Steam page, and mail there is not received by this wiki.
